# Итерация 1 — фундамент, виртуализация, харнессы и MCP

**Цель:** холст, по которому можно летать с тысячами блоков; все 22 вида артефактов на нём;
CLI-агенты, которые живут на доске в терминалах и правят её через MCP.

Первоначально харнессы и MCP стояли в итерации 5 — по решению от 2026-09-15 они подтянуты сюда.

## Что сделано

### Платформа
- Electron 33 + electron-vite + React 19, монорепо на npm workspaces
- `packages/shared` — движок teca 1:1 (геометрия, порты, роутер, раскладка, детектор, метрика)
  плюс виртуализация (`viewport.ts`), зоны, дефолты 22 типов с подсказками для модели
- `apps/desktop/src/main` — ядро сервера teca 1:1: сервис досок с историей и откатом упавшей
  транзакции, операции, тулы агента, скиллы, промпт (подробности — [PROVENANCE.md](PROVENANCE.md))
- Данные: `%APPDATA%/@zmtki/desktop/data` (`boards.json`, `skills.json`); переопределяется `ZMTKI_DATA_DIR`

### Холст
- Панорамирование колесом, перетаскиванием фона, средней кнопкой и пробел+мышь; зум Ctrl+колесо
  относительно курсора
- Выделение (клик, Shift+клик, Shift+рамка, Ctrl+A), перемещение группой, resize, снап к сетке 20px
- Стрелки: тянуть с якоря на другой артефакт; ортогональная маршрутизация и изгибы из teca
- Undo/redo (Ctrl+Z / Ctrl+Shift+Z), Delete, F — вписать всё, 0 — масштаб 100%, D — рисование, F3 — FPS
- Двойной клик по фону — заметка; перетаскивание файлов из ОС — артефакты `file`
- Зоны: рендер, подсвеченные запросы агента с «Принять / Отклонить» (режим рисования зон — итерация 6)

### Артефакты — все 22 типа ставятся и работают
| Тип | Состояние |
| --- | --- |
| note, text, markdown, document | markdown, редактирование по двойному клику |
| markdown-doc, text-editor, code-editor | редактор на доске, Ctrl+S; чтение/запись файлов — итерация 3 |
| code | код с заголовком и языком |
| html, ui | `iframe` в песочнице без доступа к родителю |
| webview, browser | Electron `<webview>` в отдельном процессе; у браузера адресная строка и навигация |
| image, video, audio | нативные элементы, ленивая загрузка |
| terminal | настоящий PTY (ConPTY) + xterm с WebGL |
| button | открывает ссылку или шлёт команду в терминал из `props.target` |
| kanban | колонки, добавление, перенос карточек мышью |
| shape, drawing, file | фигуры, рисование от руки, карточка файла |
| app-stream | **заглушка** — захват окон в итерации 4 |

### Харнессы и MCP
- MCP-сервер (Streamable HTTP) в main-процессе на `127.0.0.1`, у каждого агента свой токен в URL;
  запросы с браузерным `Origin` отклоняются
- Отдаются 21 тул teca с их JSON-схемами как есть, аргументы проходят валидатор teca
  (приводит числа-строки, которые шлют модели); ошибка операции возвращается как tool error
- В `instructions` при подключении — системный промпт teca, каталог скиллов и состояние доски
- `board_screenshot` — настоящий снимок окна через `capturePage`, если область на экране;
  иначе ASCII-схема с объяснением
- Запуск: **Claude Code** (`--mcp-config … --strict-mcp-config`), **Codex** (`-c mcp_servers.board.*`),
  OpenCode и обычный терминал. Claude Code ищется в PATH, в `~/.local/bin` и внутри расширения
  VS Code / Cursor
- Агент = терминал-артефакт + PTY + MCP-токен, живут и умирают вместе. Удалил терминал — агент
  остановлен и лишён доступа
- Маркер агента на доске: рамка вокруг того, что он трогал последним, подпись с тулом и пунктир
  к его терминалу. Боковая панель: статус, счётчик вызовов, последняя ошибка, «К терминалу»,
  «К месту работы». Сам терминал в панель не сворачивается

## Механика производительности

1. **Камера мимо React.** Пан и зум копятся и применяются раз в кадр прямо в `transform` сцены
   и фон сетки. React видит камеру раз в 90 мс — этого хватает для culling
2. **`will-change` только на время жеста** (идея из CanvasTTY): в покое сцена перерастеризуется
   в новом масштабе, текст не мылится
3. **Culling через `SpatialIndex`** — равномерная сетка; монтируется видимое + 400px overscan
4. **Уровни детализации** по зуму: полный → упрощённый (подпись без markdown/iframe/медиа) →
   **обзор на одном `<canvas>`** — прямоугольники пакетами по цвету, стрелки из заранее
   собранного `Float32Array`
5. **Во время жеста ничего тяжёлого не монтируется:** новые карточки встают упрощёнными и
   дорисовываются при остановке; в обзор можно уйти посреди жеста, выйти — только после
6. **Живые артефакты не размонтируются** — терминал за краем экрана скрыт, но работает
7. **Перетаскивание не трогает доску:** черновики геометрии в отдельном срезе стора, коммит
   один раз при отпускании; стрелки считаются только для смонтированных карточек
8. **Вывод PTY батчится по кадру** (16 мс), скроллбэк ограничен 200 000 символов

## Замеры

`npm run bench -- <N>`: собирает приложение, открывает доску из N артефактов кластерами по 24
со стрелками внутри, облетает её камерой через те же `panBy`/`zoomAt`, что и мышь, и пишет
отчёт в `bench.jsonl`. Между фазами пауза 0,5 с, как у человека.

Машина разработки, монитор 60 Гц, Electron 33. FPS — средний, p95 — 95-й перцентиль длительности кадра.

| Доска | пан 100% | отдаление | пан в обзоре | приближение | пан 50% | в DOM макс. |
| --- | --- | --- | --- | --- | --- | --- |
| 10 (потолок машины) | 55.6 / 18.3 мс | 56.0 / 18.2 | 55.9 / 18.3 | 56.2 / 18.3 | 56.7 / 18.2 | 10 |
| 5 000, первый прогон | 53.2 / 18.3 | **36.3 / 71.6** | — ¹ | — ¹ | — ¹ | 276 |
| 5 000, итог | 53.5 / 18.4 | 54.7 / 20.6 | 55.4 / 19.0 | 55.2 / 19.0 | 55.7 / 18.2 | 82 |
| 10 000, итог | 53.1 / 18.3 | 53.3 / 19.0 | 55.7 / 19.1 | 55.2 / 21.0 | 50.6 / 36.0 | 82 |

¹ в первом прогоне маршрут уходил за пределы доски, эти фазы мерили пустоту.

Итог: 5 000 артефактов — 54.8 FPS в среднем при потолке 56 (98%), 10 000 — 53.6 (96%).
Что дало прирост на отдалении (36 → 55 FPS): упрощённые карточки во время жеста и ранний
уход в обзор; в обзоре — пакетная отрисовка по цвету.

## Известные ограничения

- **Смена доски целиком по IPC.** Любое изменение шлёт в рендерер всю доску, а история хранит
  полные снимки состояния (из teca). На 10 000 артефактов это заметно на частых правках агента.
  Следующий шаг — дельты и патчи в истории
- **xterm внутри масштабируемой сцены**: при зуме ≠ 100% выделение текста мышью смещено, а
  WebGL-холст терминала мылится при сильном приближении
- **app-stream** — заглушка до итерации 4
- **Редакторы файлов** хранят текст в артефакте; чтение и запись файлов с диска — итерация 3
- `board_screenshot` снимает только то, что сейчас видно на экране
- Артефакт из меню или панели агентов встаёт ровно в центр экрана и может лечь поверх соседа —
  нужен поиск свободного места рядом (движок для этого есть: `rankArtifactPlacements`)
- Codex и OpenCode не проверены вживую — на машине не установлены. Claude Code найден
  (расширение VS Code), флаги `--mcp-config` / `--strict-mcp-config` сверены с его `--help`;
  путь MCP проверен интеграционным тестом через настоящий MCP-клиент по HTTP

# Итерация 2 — плавность, размещение перетаскиванием, бренд

**Запрос (2026-09-15):** исправить ограничения итерации 1; новые блоки перетаскиваются на доску,
а не возникают неожиданно; всё происходит плавно — перетаскивание, удаление агентом,
короткие и дальние перемещения; анимации только когда пользователь смотрит; у листания доски
инерция; иконка Z и полный логотип в интерфейсе.

Прежнее содержимое итерации 2 (метрика качества в интерфейсе, кнопка раскладки, офлайн-стенд
teca) переехало в итерацию 3 — см. [PLAN.md](../PLAN.md).

## Исправленные ограничения итерации 1

| Было | Стало |
| --- | --- |
| Любое изменение шлёт в окно всю доску; история — полные снимки (60 × размер доски) | События-**дельты**: только затронутые сущности и номер версии. История — **патчи** «туда/обратно». Пропуск версии → окно перезапрашивает доску. Файл данных без отступов |
| Терминал при зуме ≠ 100%: смещённое выделение мышью, мыльный текст | Терминал раскладывается в масштабе доски и сжимается обратно — на экране 1:1, текст чёткий, координаты мыши точные. Столбцы/строки PTY при зуме не меняются |
| Новый блок встаёт в центр экрана поверх соседа | Блок **несётся к месту** курсором, превью показывает, куда ляжет; место сдвигается к ближайшему свободному (`findFreeSpot`). Двойной клик и файлы из ОС тоже не ложатся поверх |

## Что сделано

### Размещение
- «+ Блок» и харнессы в правой панели: **тянуть на доску** или **нажать и кликнуть по месту**;
  Esc или правая кнопка — отмена
- Пунктирное превью реального размера с названием, скользит между свободными местами
- Упавший блок проявляется анимацией появления

### Анимации — только когда видно
Изменение анимируется, если окно видно (`visibilityState`) и старое или новое место попадает в
экран. Иначе применяется мгновенно. Источник не важен: агент, свой undo/redo, своя правка.

| Событие | Как выглядит |
| --- | --- |
| Появление (агент, сброс блока, undo удаления) | подъём из 92% с проявлением, 340 мс |
| Короткое перемещение/resize (до 60% экрана, оба конца видны) | плавный сдвиг 260–620 мс, **стрелки едут вместе с блоком** — геометрия пересчитывается каждый кадр |
| Дальнее перемещение | гаснет на старом месте 260 мс, проявляется на новом с задержкой 140 мс |
| Удаление (агентом или клавишей Delete) | медленно сжимается до 55% с затуханием, из центра расходится тонкое кольцо, 480 мс |
| Перетаскивание | карточка «приподнимается» (тень, 101.5%), при отпускании **доезжает** до сетки 20px |
| Меню, тосты, маркеры агентов, кнопки | короткие проявления и переходы |

`prefers-reduced-motion` в системе — анимации сводятся к мгновенным.

### Камера
- **Инерция**: брошенная доска скользит с затуханием (τ = 320 мс), любое касание останавливает
- Колесо мыши и Ctrl+колесо — плавные шаги вместо рывков; тачпад и щипок — напрямую
- «Вписать всё» (F), 100% (0), «К терминалу», «К месту работы» — **перелёт** с интерполяцией
  центра и логарифма зума (без бокового заноса)

### Бренд
- Логотип в тулбаре и на пустой доске, иконка окна и вкладки
- Интерфейсный акцент — оранжевый из логотипа
- Файлы: `apps/desktop/resources/logo.png` и `icon.png`. Пока их нет — нарисованный CSS
  вордмарк в тех же цветах и стандартная иконка Electron

### По ходу
- Горячие клавиши (F, Delete, Ctrl+Z) не работали после клика по кнопке тулбара — исправлено
- Колесо мыши при масштабировании экрана Windows распознавалось как тачпад (дробные дельты)
  и зумило в 2,7 раза за щелчок — исправлено
- `backgroundThrottling` отключается только для бенча: свёрнутое приложение больше не рисует

## Производительность

Анимации и новая камера сначала **просели**: p95 кадра в фазах зума и обзора — 33 мс вместо
17. Профиль CPU показал, что JS простаивает на 83%, бисекция CSS ничего не дала — проблема была
в растеризации и в одном алгоритме:

| Причина | Исправление |
| --- | --- |
| Обзорный canvas: 5 000 прямоугольников одним контуром — Skia тесселирует его на GPU | `fillRect` вдали; скругления, обводки и подписи — только когда камера остановилась |
| `approachLength` в движке стрелок перебирал **все** артефакты доски на каждый порт — 31% CPU при пане 10 000 | `arrowGeometryScope`: концы стрелок и соседи в пределах 81px из пространственного индекса. Геометрия **идентична** — доказано тестом на плотной доске. Код teca не менялся |
| Поиск стрелок видимых карточек — проход по всем стрелкам на каждом снимке камеры | индекс «артефакт → стрелки» раз на изменение доски |
| Неактивный обзорный canvas очищался каждый кадр | отписывается от камеры |

Замеры `npm run bench -- N`, монитор 60 Гц, потолок машины в момент замера — 59,5 / 16,9 мс
(доска из 10 артефактов). Параллельно работал ещё один экземпляр приложения с агентом.

| Доска | пан 100% | отдаление | пан в обзоре | приближение | пан 50% | средний / p95 |

| 5 000, итерация 1 | 53.5 / 18.4 | 54.7 / 20.6 | 55.4 / 19.0 | 55.2 / 19.0 | 55.7 / 18.2 | 54.8 / 19.0 |
| 10 000, итерация 1 | 53.1 / 18.3 | 53.3 / 19.0 | 55.7 / 19.1 | 55.2 / 21.0 | 50.6 / 36.0 | 53.6 / 19.1 |

между итерациями нельзя, сравнивайте долю от потолка. Итерация 2: 99% на обеих досках.

## Известные ограничения

- Логотип и иконка ждут файлов в `apps/desktop/resources/` (картинки из чата на диск не попадают)
- Выделение мышью в терминале точно при зуме 25–400%; во время самого жеста зума, до остановки
  камеры, возможен сдвиг на долю символа
- При телепорте стрелки блока прыгают сразу на новое место, без проявления
- Иконка для собранного `.exe` (формат `.ico`) — при упаковке приложения
